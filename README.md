# HTML OS Android

نسخه اندرویدی آفلاین از فایل HTML OS.

- رابط اصلی از فایل محلی داخل برنامه بارگذاری می‌شود.
- برای اجرای خود برنامه، اتصال اینترنت یا مجوز INTERNET لازم نیست.
- داده‌های IndexedDB و LocalStorage در WebView نگهداری می‌شوند.
- فایل HTML اپلیکیشن‌ها و فایل بکاپ از طریق انتخاب‌گر فایل اندروید قابل انتخاب هستند.

## ساخت APK
از تب Actions، گردش‌کار **Build HTML OS APK** را اجرا کنید یا با هر push به شاخه main به‌صورت خودکار ساخته می‌شود. خروجی در بخش Artifacts با نام HTML-OS-debug-APK قرار می‌گیرد.
