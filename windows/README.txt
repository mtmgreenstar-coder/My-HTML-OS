HTML OS for Windows (64-bit)
============================

How to run:
1. Extract the entire ZIP file into a normal folder.
2. Open HTML-OS.exe.
3. Keep the assets folder next to the EXE.

The app loads the HTML OS files locally. Its app data (installed HTML apps,
icons, and preferences) is stored in your Windows user profile so it remains
available after closing and reopening the app.

Requirements:
- Windows 10/11 64-bit.
- Microsoft Edge WebView2 Runtime. It is included with most current Windows
  installations. If it is missing, install the official Microsoft WebView2
  Runtime, then reopen HTML OS.

Shortcuts:
- F11: Full screen
- Ctrl+R: Reload
- Alt+F4: Exit

This is a portable folder build. Do not run the EXE from inside the ZIP.
